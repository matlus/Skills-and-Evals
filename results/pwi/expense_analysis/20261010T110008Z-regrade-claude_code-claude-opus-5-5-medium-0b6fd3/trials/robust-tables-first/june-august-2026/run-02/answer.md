### The code

The script (`parse.py`):
- Matches each merchant against a dictionary. Longer names are checked first, so "Amazon Prime" doesn't get matched as "Amazon" and "Planet Fitness App" doesn't get matched as "Planet Fitness."
- Reads dates in four formats: `2026-MM-DD`, `M/D(/26)`, `MM-DD` and `Mon(th). D`.
- Finds the single amount on each line and treats a leading `-` as negative.
- Removes exact duplicates (same date, merchant and amount) and lists same-merchant charges within 2 days for review.
- Adds up the totals with `defaultdict` sums.

A second script printed all 198 parsed rows next to the original lines. I checked every row by eye.
